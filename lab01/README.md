
# Лабораторна робота №1
## Основи функціонального програмування у Python

**Варіант 13 — Страхові поліси**

### Мета роботи

Ознайомитися з чистими функціями, референтною прозорістю,
ізоляцією побічних ефектів та використанням `typing.Callable`.

### Опис програми

Програма розраховує кінцеві страхові премії для активних
полісів з урахуванням рівня ризику та стажу клієнта.

Коефіцієнт ризику, політика знижок і фільтр активності
передаються як функції.

### Структура проєкту

- `core.py` — чисті функції та обробник полісів.
- `app.py` — приклад використання програми та виведення звіту.
- `tests/test_core.py` — автоматичні тести.
- `requirements.txt` — інструменти розробки.
- `README.md` — опис проєкту та інструкція запуску.

### Принципи функціонального програмування

- Обчислення не залежать від глобального стану.
- Вхідні дані не змінюються.
- Політики ризику, знижок і фільтрації передаються через `Callable`.
- Виведення результатів відокремлене від обчислень.
- Результат можна перевірити автоматичними тестами.

### Встановлення

```bash
python -m pip install -r requirements.txt
```

### Запуск програми

```bash
python app.py
```

### Запуск тестів

```bash
python -m pytest -v
```

### Перевірка типів

```bash
python -m mypy core.py app.py tests
```

### Перевірка форматування

```bash
python -m black --check core.py app.py tests
```

### Статичний аналіз

```bash
python -m ruff check core.py app.py tests
```
